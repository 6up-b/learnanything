### A. Ten lines for the owner

1. A completed Ask can reduce the value of the learner’s next answer even if the reply never reaches their screen. The debit is committed before the server returns the answer. `src/learnloop/tutor/tutor_qa.py:1312,1337,1374`
2. The opposite error occurs in “Ask the tutor” from pinned library results. The workbench item filters the books, then drops out of the call that accounts for help. `src/learnloop_sidecar/handlers/library_ask.py:794–808`
3. When tutor retrieval falls back to linked passages, an item’s own solution can reach the tutor and a citation chip. That branch also misses the citation debit. `src/learnloop/tutor/tutor_qa.py:1227–1233,1374,2389–2401`
4. The phone protects the selected passage more thoroughly than the surrounding passages and earlier answers included in the same request. `src/learnloop_sidecar/handlers/reader.py:149–156,224–244`, `src/learnloop/reader/reader_dialogue.py:277–312,648–676,1003–1016`
5. A new protection mark takes effect on a fresh search but can be bypassed by reopening organizer notes or retrieving a completed phone job. `src/learnloop/source_retrieval/library_ask.py:871–878`, `src/learnloop_mobile/host.py:403–407,604–609`
6. A Reader excerpt can reproduce a reserved question without retiring it from unseen use. The Teacher can put a live check’s answer in a choice without withdrawing the check. `src/learnloop/reader/reader_dialogue.py:776–782`, `src/learnloop/teacher/service.py:1297–1318,1715–1720`
7. Compare can return an item’s own passage before reaching its post-attempt debit. Find Sources charges for that same passage. `src/learnloop/source_retrieval/compare.py:544–549,577–583,695–702`, `src/learnloop/source_retrieval/find_sources.py:835,896`
8. Coverage can reuse an answer after the question asked of the judge has changed. Two different topics can also end up pointing to the same topic’s judgment row. `src/learnloop/source_retrieval/section_coverage.py:663–671,769–817,1284–1285`, `src/learnloop/practice_index/listwise.py:119–132`
9. The book Guide has a database claim for paid work. The daily deliverable refresh has a process-local claim, a local-calendar start flag and a deadline calculation in UTC. `src/learnloop/source_retrieval/reading_paths.py:772–833`, `src/learnloop_sidecar/handlers/deliverables.py:344–375`, `src/learnloop/source_retrieval/deliverable_path.py:407–414`
10. G6 needs parity tests at the model, delivery and replay boundaries. DJ1 and DJ5 need the exact fields actually displayed. DJ7 needs separate identities for a reusable model answer and the question to which that answer belongs. `docs/specs/refactor_strategy_v3.md:463,749`, `docs/specs/spec_semantic_judgments_v1.md:53,80,153–158`
