# G3. Measure the disagreement

**G4 verdict at `f8300a3f00`: do the narrow part now, decide the rest after G1.** Measured on a fresh backup copy of the owner's live arxiv vault (2026-11-18): five probes presented since Nov 7, four answered, four pairs. In none of the four do the two records name different causes, but in all four the episode posterior ends with a leading cause while the discriminating observation resolves nothing (no pre-registered prediction matched in any of them). In three of the four the discriminating observation refused the answer as not independent (feedback had been shown, or the answer came after a reveal), and the episode posterior still counted the same answer at full weight, with no discount. So on real data the two channels do treat the same answer differently, in the direction the strategy named (independence refused in one and not in the other). Four pairs cannot size a belief unification, but they are every real pair there is, and three of them show the same defect: ledger row G3-1 (the episode posterior counts an exposed probe answer as clean evidence). That narrow fix is worth doing now; the full G4 (one posterior serving both) is decided after G1, with a rerun of this measurement. An earlier version of this record said no probe had ever been presented: that was true only of the comparison copies, which were made from an October set and miss all of the vault's November use. ## Pairing and counts

The scratch script joins A's **probe_attempt_id** to `probe_observations.attempt_id` through `practice_attempts.id` and requires A's `presentation_id` to equal the attempt's `probe_presentation_id`. A's own `attempt_id` identifies the original diagnosed miss. Null answer IDs and learner-question receipts are counted separately. Duplicate A candidates are reported as ambiguous. Each ledger reconciles to pairs plus unpaired rows. For missing partners the script distinguishes an invalidated presentation, a missing causal pin, a recorded classifier decline and missing evidence of a reason. [Receipt schema](../../migrations/130_causal_discriminating_observations.sql#L49) · [Unique answer and presentation keys](../../migrations/028_probe_episodes.sql#L98)

A supplies a cause only when its receipt closed the factor. The script flags admitted matching support without closure separately among disagreements. B supplies the unique concrete maximum of the stored after-posterior. Ties and a winning open arm count as undecided. A held row can retain an earlier leader. This compares beliefs immediately after submission. Episode completion also requires probability, ambiguity and breadth tests. For equal leaders the script records A's raw support, B's raw posterior mass and their absolute numerical difference, with no rescaling. [Episode top](../../src/learnloop/diagnosis/probe_episodes.py#L119) · [Completion](../../src/learnloop/diagnosis/probe_completion.py#L111)

A's receipt and B's presentation→episode link identify their respective `hypothesis_sets`. The script compares ordered labels and pinned versions, counts missing/extra labels relative to A and reordering among common labels, and reports ID, prior and prior-basis changes separately. Among different or one-sided leaders, it counts overlapping recorded conditions: B's submission hold, any criterion marked unassessed at B's write, A's explicit independence refusal or B's contamination, and different locks. It records unknown evidence separately. These are associations. [Unassessed stamp](../../src/learnloop/outcome_contract.py#L64)

**SQL inputs.** A uses `id, factor_id, attempt_id, probe_attempt_id, presentation_id, hypothesis_set_id, channel, outcome, classified_as_json, admitted, admission_reason, feature_source, support_scores_json, resolved_factor, admissible_as_independent, inadmissibility_reason, created_at`. B uses `id, attempt_id, posterior_before_json, posterior_after_json, contamination_json, independent_evidence_discount, grader_channel_json, updates_belief, eligible_for_completion, created_at`. The join also reads attempt ID, presentation ID and time, presentation ID, episode ID, selection components and end state, episode ID and set ID, and set ID, hypotheses, prior and prior basis. Grade flags use `grading_evidence.attempt_id, attribution_json, created_at, superseded_at`. Declines, if available, use `decision_records.kind, subject_id, status`. The script requests a backup-API working copy of each primary database, reads it with plain SQL in URI `mode=ro`, and removes the copies on exit.

## Which readers could change

The scoreboard directly counts admitted receipts that closed a factor (`diagnosis/scoreboard.py:1328–1338`, paths relative to `src/learnloop/`). Causal health counts outcomes, sensors and admissions (`diagnosis/causal_health.py:284–296`). EVSI calibration reads the independent single match and forecast linkage (`evsi_calibration/live_report.py:742–761,795–808,888–898`). Deferral tests whether a receipt exists (`diagnosis/causal_factor_deferral.py:345–355`). The picks and capture reports compare picks or marks with classified causes (`router_objective/picks.py:82–87,111–119`, `ops/capture_report.py:286–303,317–342`). Hypothesis marks exposes the latest answered classification through the probe state (`db/stores/hypothesis_marks.py:157–166`, `followup_serve/marks.py:103–126`). Instructional valuation reads the replayed episode posterior and renormalizes concrete mass (`instructional/valuation.py:208–230`). A change to the closure bit alone directly affects the scoreboard formula. Reports retaining the pre-registered match can still report that match. On the four real pairs, the readers of the discriminating observation saw no resolution, while `instructional/valuation`, which reads the episode posterior, saw a posterior moved by three answers the other channel had refused.
