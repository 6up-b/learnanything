`claim_prior(inputs: ClaimPriorInputs) -> tuple[MasteryState, DecisionRecord]`

Add `reanchor(current, prior_inputs, incoming_claim) -> (state, record)`. Shell retains claim queries, atomic replacement/application-position writes and mastery upsert. `field.priors` queries once and passes values instead of constructing fake repositories.

**Proof:** a new literal-input test calls the core for superseded claims, recency ties and retained variance. Simplify the numerical portions of `test_lp_claim_fixes.py::test_defect4_on_the_most_recent_claim_wins_then_pseudo_count_never_level`, `test_lp_claim_fixes_rereview.py::test_f8_two_claims_with_differing_pseudo_counts_keep_the_weak_claims_variance_in_a_rebuild`, and both `test_field_priors.py` tests. Keep transactional/replay tests.

`choose_slot(inputs: SlotInputs) -> tuple[SlotOutcome, DecisionRecord]`

**Proof:** literal posterior/specifications test covers substitution, predecessor and empty support, returning the same row payload/propensities.
