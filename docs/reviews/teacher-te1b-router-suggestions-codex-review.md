| F7 | Medium | The acceptance model cannot learn spacing beyond one day | **fixed** | backend commit | The days-since-last-suggestion feature is now `1/(1+c) − 1/(1+d)`, with `c = LEGACY_CADENCE_DAYS = 1` (seeded, basis legacy, registered).
