# The plan

Make the smallest tree that gets from what the learner holds to the goal. Store it with `write_plan` (nodes
with an id, a one-line statement, the topic id when there is one, the passages it rests on, and the nodes it
depends on). Present it in a few sentences as a map of landmarks, not a syllabus, and end that turn: the
learner's reply is either the go-ahead or a change. Move the plan whenever the learner turns out different
from it. A node is a position on the map, never a completion.
