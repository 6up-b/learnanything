notebooks, widgets, fonts or binary assets are vendored here. Exact requirements
are in pyproject.toml and resolved artifacts and hashes are in uv.lock.
Existing frontend engine notices remain beside those engines.

Fonts bundled with the desktop app (Reader workbench v2, the desks)
==================================================================

The desks' four fonts are npm dependencies of apps/learnloop-tauri, pinned exactly in
package.json and resolved in package-lock.json. No font file is committed: Vite copies the
packages' WOFF2 files into the built app, so the app fetches no font from a font service.
Each is licensed under the SIL Open Font License, Version 1.1 (OFL-1.1); the full licence
text ships in each package's LICENSE file and is preserved when the app is distributed.
