# What do you mean by additive identity

**Q (practice):** What do you mean by additive identity

**A:** An **additive identity** is an element—call it \(e\)—that leaves every vector unchanged when added using the specified addition operation:

\[
v\oplus e=e\oplus v=v \quad \text{for every } v\in V.
\]

Here the relevant addition is \(\oplus\), not ordinary coordinate-wise addition. To find \(e\), use the definition of \(\oplus\) and ask: what must \(T(e)\) be so that \(T(v)+T(e)=T(v)\) for every \(v\)?
